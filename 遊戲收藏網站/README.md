# 遊戲收藏網站

需要 Node.js 18 或更新版本。解壓縮後，在該資料夾執行 `node server.cjs`，電腦可開啟 http://localhost:8080。部署時使用支援 Node.js 的主機，設定 HTTPS 與持久磁碟，並將 ARCADE_DATA_DIR 指向該磁碟。PORT 預設為 8080。請使用單一伺服器程序。同步碼如同密碼，請透過安全管道傳到自己的另一台裝置。

先在首頁建立同步碼，再開始遊戲。換裝置時在首頁貼上相同同步碼，開啟遊戲即可載入進度。換裝置前等畫面顯示「已同步」。訪客本機進度和同步進度各自保存。火山戰神在每轉結束時存檔，麻將在牌局狀態更新時存檔。
